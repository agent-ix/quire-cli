## Findings

| ID | Severity | Summary | Refs |
| --- | --- | --- | --- |
| FND-001 | medium | PLAT-1603 AC-4 ("Wide tables remain readable (landscape or wrapping, per the spec)") has no spec text and no test. FR-031 states no wide-table rule, and the PR relies on pandoc using the relative separator dash counts (clamped to 3..48) once a source line passes 72 columns. No test asserts the separator widths, so a regression to 3-dash separators passes every test. The soup table has 14 columns, several of them compact JSON with no break opportunity (`{"state":"stated","items":["FR-901"]}`), which Typst's line breaker cannot wrap, so PDF overflow is plausible and unverified. Add the chosen rule (wrapping with relative widths, or landscape above N columns) to FR-031 with an AC. Assert the separator widths in a stand-in test, and the page fit of the soup fixture in the real-converter test. | src/commands/export/json.rs:93-110, spec/functional/FR-031-export-subcommand.md |
| FND-002 | medium | FR-031-AC-11 (and AC-9 for the pack index) asks for content "present in the extracted text", but the only extraction test checks less than the AC requires. Its soup needles omit the `As of` line and `scans/broken-scan-1.json` (AC-11: "the As of line … and every unreadable_scans entry"), and its pack needles do not check the index table (AC-9: "also yields its index table"). The stand-in tests check these only in the Markdown handed to the converter. Add `As of: 2026-11-12`, `broken-scan-1.json` and an index-row needle (for example the `rowCount` text or `set-b`) to `real_converters_keep_every_report_row_id`. | tests/cli_export.rs:1112-1175 |
