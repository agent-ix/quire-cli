## Verdict

FAIL. FR-034-AC-6 is untagged and would fail if tested, and FR-031-AC-7 and FR-035-AC-7 are untagged.

Every other in-scope FR-034 criterion is tagged by a non-ignored test that would fail on a real regression: the committed blob, the commit date, the release tag, the older rev, the CRLF case, the filter refusal, the JSON refusals, the hostile values in metadata and front matter, and the YAML-block neutralisation.

Reverse gap:
- No production code without an owning requirement was found.
- `--source-repo`, `--source-rev` and `--release` are owned by FR-034.
- The stored-ZIP writer and the Typst template are owned by FR-035 B.

Stub check: no stubs and no `todo!`. No inflated tags beyond the FR-032-AC-5 binding noted in FND-001.
