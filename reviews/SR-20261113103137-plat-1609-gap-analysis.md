## Summary

Ticket: PLAT-1609. Planless gap analysis of FR-037 and NFR-011 against the PR's tests and code. Plan completion: not assessed. Trace bindings come from `quire trace --id`. `quoin matrix` (0.30.1) reports every Test AC in this repository as `untagged`, including ones on main with `#[trace]` markers, so it was not used. That is a tooling observation, not a finding against this PR.

Ticket ACs. AC "two exports give identical extracted text and structure for PDF and DOCX" is backed only by the ignored real test `real_exports_give_equal_text_and_structure_across_directories_and_zones`. It was not run, because pandoc, typst and pdftotext are not installed here; deferring that run is acceptable per the brief. AC "no wall-clock time, random id or host path in the output" is backed by the three always-run stand-in tests, which cover requests and every generated input, and by the ignored `real_documents_hold_the_commit_time_or_none_and_no_host_path`. FR-037-AC-1 is fully and soundly covered by the stand-ins: the environment keys are exactly the three, and the epoch is 981261000 (2001-02-04T04:30:00Z, the fixture commit) or 0 for a JSON report. NFR-011-AC-4 (a one-word change differs) is in the real test. NFR-011-AC-5 (Mermaid) depends on FR-042, which is not in this tree, and is not claimed.

## Verdict

Changes requested. The code satisfies FR-037. The only leak, the missing `SOURCE_DATE_EPOCH` on JSON reports, is fixed, and no other leak exists on the input-to-request path. FR-037-AC-1 is soundly tested. FND-001 to FND-004 are evidence gaps: NFR-011 is claimed by tests that do not measure it, and the real tests do not yet exercise the clock, the DOCX organisation template or the PDF structure. None is a production defect. Real-converter runs (`make test-export-real`) are deferred to a host with pandoc, typst and poppler-utils.
